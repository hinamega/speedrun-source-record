# Speedrun Source Record

OBS Studio向けフィルタープラグインです。[exeldro氏の obs-source-record](https://github.com/exeldro/obs-source-record) をベースに、RTA（スピードラン）走者向けに特化してフォーク・開発されています。

LiveSplitと連動し、タイマーの開始・終了に合わせてゲーム画面（クリーンフィード）の自動録画、テイク数やカテゴリを含めたファイル名自動生成、リセット時の動画の reset_runs フォルダへの自動隔離を行います。

## 主な機能

- **LiveSplit連動**: タイマーのスタート・フィニッシュを検知して録画を自動制御します。
- **スタート前バッファ（プレバッファ）＆自動無劣化結合**: タイマースタート直前のN秒間（既定5秒）も逃さず記録に含めます。完走時、OBS同梱のFFmpegエンジンを用いてプレバッファと本編動画を無劣化（ストリームコピー）で即座に1本へ自動結合します。FFmpeg等の外部ツールのインストールは一切不要で、プラグイン単体で完全自己完結して動作します。
- **ゴール後バッファ**: タイマーストップ後、指定秒数だけ録画を継続してから安全にファイルを保存します（リザルト画面の記録など）。
- **ファイル名への自動タグ埋め込み**: ファイル名書式で `%game%`（ゲーム名）、`%category%`（カテゴリ名）、`%attempt%`（テイク数/試行回数）が使用できます。
- **リセット動画の自動隔離**: 途中でタイマーをリセットした場合、動画ファイルを自動で録画先フォルダ内の `reset_runs` サブフォルダへ移動・隔離します（完走テイクのみがスッキリ残り、完全削除ではないため後からの見直しや救出も可能です）。プレバッファの一時ファイルは自動消去されます。
- **映像のみ録画オプション**: 音声エンコード処理をバイパスし、負荷を最小限に抑えてゲーム画面のみを軽量に記録できます。

## 音声について

本プラグインは **フィルターを追加したソースの音声**を録音します。**ゲームキャプチャ本体**に追加してください。

- ゲーム音は自動的に録音されます（フィルター対象ソースの音声）。
- **マイクは既定では録音されません**（マイクは別ソースのため）。
- **「映像のみ録画 (音声なし)」は音声を一切録音しません。既定ではOFF**なので、ゲーム音を残す場合はOFFのままにしてください。

> [!IMPORTANT]
> フィルター対象ソースが音声を出力している必要があります。OBSのゲームキャプチャなら「音声をキャプチャ」を有効にするか、**アプリケーション音声キャプチャ**を音声ソースとして用意し、フィルターの「Different Audio」で指定してください。シーンにフィルターを追加すると、マイクが混ざることがあります。

マイクや特定のOBS音声トラックを録音したい場合は、「Different Audio」を有効にしてソース／トラックを選択してください。

## 必要な環境・使い方

### 1. LiveSplit側の設定
本プラグインは LiveSplit の TCP サーバー機能（既定ポート: 16834）と通信します。お使いの LiveSplit のバージョンに応じて以下の手順で準備してください。

#### 通常の公式リリース版（LiveSplit 1.8.x）をお使いの場合
1. [LiveSplit.Server のリリースページ](https://github.com/LiveSplit/LiveSplit.Server/releases) から最新の `LiveSplit.Server.zip` をダウンロードします。
2. 解凍したファイル（`LiveSplit.Server.dll` 等）を LiveSplit インストール先の `Components` フォルダに配置します。
3. LiveSplit を起動し、右クリック -> `Edit Layout` -> `+` ボタン -> `Control` -> `LiveSplit Server` を追加して `OK` を押します。
4. LiveSplit 上で右クリック -> `Control` -> `Start Server` を選択してサーバーを開始します（既定ポート: 16834）。

#### 開発版（LiveSplit DevBuild）をお使いの場合
1. 開発版にはサーバー機能が最初から内蔵されています。
2. LiveSplit 上で右クリック -> `Control` -> `Start TCP Server` を選択してサーバーを開始します。

> [!NOTE]
> サーバー機能はどちらのバージョンでも、LiveSplit を起動するたびに手動で開始（Start）する必要があります。

### 2. OBS Studio側の設定
1. 録画したいゲームキャプチャや映像ソースのフィルターに「Speedrun Source Record」を追加します。
2. 録画モードを「LiveSplit (RTA自動録画)」に設定します。
3. ファイル名書式をお好みに合わせて設定します（例: `%game%_%category%_Run%attempt%_%CCYY-%MM-%DD_%hh-%mm-%ss`）。
4. 必要に応じてスタート前バッファ時間（プレバッファ）、ゴール後バッファ時間や、「リセット時の動画を 'reset_runs' フォルダに移動」のON/OFFを設定します。
